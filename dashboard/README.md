# Reviewer UI

The implemented Streamlit reviewer lives in [src/medical_imaging_platform/reviewer_ui](../src/medical_imaging_platform/reviewer_ui).
It calls the governed API, displays segmentation overlays and retrieval rankings, and records
separate review decisions. See [review workflow](../docs/reviewer_workflow.md) and
[local startup](../docs/local_startup.md). Review acceptance is not clinical approval.
