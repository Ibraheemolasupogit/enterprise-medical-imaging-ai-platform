# Excluded Use

The platform must not be used as:

- An autonomous diagnostic system.
- A replacement for a radiologist.
- An approved medical device.
- A clinically validated NHS deployment.
- A patient-management tool.
- A malignancy-versus-benignity classifier unless a suitable labelled public dataset is identified and its limitations are documented.
- A live AWS clinical deployment.
- A system that automatically promotes, retrains or rolls back models.
- A source of clinical safety surveillance, post-market monitoring or regulated clinical audit evidence.
