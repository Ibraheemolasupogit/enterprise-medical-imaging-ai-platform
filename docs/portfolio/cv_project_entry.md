# CV Project Entry

This platform is a research and engineering demonstrator. Outputs are intended for technical
evaluation and human review only and must not be used for clinical diagnosis or patient-management
decisions.

## CV Entry

Built an end-to-end medical-imaging AI engineering demonstrator for abdominal CT workflows using
Python, PyTorch, MONAI, FastAPI, Streamlit, Docker, Helm/Kubernetes and Terraform. The project covers
synthetic CT fixture generation, governed DICOM ingestion/de-identification, image QC,
preprocessing, registration, adrenal-region localisation, segmentation, calibrated classification,
longitudinal analysis, model registry, monitoring/drift/audit evidence, secure container and
Kubernetes assurance, AWS target-state infrastructure, observability, incident-response runbooks and
portfolio evidence. All claims are bounded to synthetic or public de-identified data; the repository
is not a diagnostic system or approved medical device.
