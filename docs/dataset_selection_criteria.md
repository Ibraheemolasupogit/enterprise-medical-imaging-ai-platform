# Dataset Selection Criteria

Future public de-identified datasets must be reviewed before use.

Selection criteria:

- Clear licence and permitted use.
- Documented provenance.
- De-identification status.
- Body region and modality alignment with the project scope.
- Label quality and annotation process.
- Patient-level identifiers for safe splitting.
- Scanner and protocol metadata.
- Dataset size and class balance.
- Known limitations.
- Restrictions on redistribution.

Do not automatically download public datasets. Do not commit real patient data. Public datasets require licensing, provenance, and de-identification review before any future integration.
