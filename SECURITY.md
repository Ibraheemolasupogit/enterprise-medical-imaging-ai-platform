# Security

Please do not report vulnerabilities using public issues if they may expose sensitive details.

## Data Safety

This repository must not contain:

- Real patient data.
- Identifiable DICOM metadata.
- Burned-in identifying image content.
- Credentials, tokens, or cloud account details.
- Restricted model artefacts.

## Supported Status

Milestone 1 contains repository foundation code only. Medical-imaging, API, deployment, cloud, and model-serving surfaces are Planned - not yet implemented.
