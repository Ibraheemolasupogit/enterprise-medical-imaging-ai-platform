# Classification Baseline Model Card

This platform is a research and engineering demonstrator. Outputs are intended for technical evaluation and human review only and must not be used for clinical diagnosis or patient-management decisions.

## Model Purpose

The Milestone 9 model is a small PyTorch 3D convolutional classifier for binary synthetic
lesion-presence experiments on repository-generated ROI-like crops. It exists to prove
classification training, calibration, threshold selection, inference abstention, evidence export,
and quality gates.

## Intended Use

Use only with repository-generated synthetic engineering fixtures for local research engineering
validation. Outputs require human engineering review.

## Excluded Use

Do not use this model for benign-versus-malignant classification, adrenal-tumour diagnosis,
radiologist triage, NHS deployment, medical-device workflows, patient-management decisions, or any
real-patient inference.

## Training Data

Training uses synthetic CT-like arrays and synthetic lesion masks generated by this repository. No
real patient data, public dataset, pretrained model, downloaded model artefact, or protected health
information is used.

## Evaluation Data

Validation and test samples are synthetic and split by research subject. Negative timepoints are
retained. Synthetic validation metrics are used for calibration and threshold selection; synthetic
test metrics are evidence only and are not clinical-performance evidence.

## Architecture

The baseline is an original compact 3D CNN with configurable convolution blocks, instance
normalisation, ReLU activations, max pooling, global average pooling, dropout, and one binary logit.
The default verification configuration is deliberately small for CPU execution.

## Metrics

Evidence includes loss, AUROC, AUPRC, sensitivity/recall, specificity, precision, negative
predictive value, F1, accuracy, Brier score, expected calibration error, calibration slope and
intercept, confusion counts, false positives, and false negatives.

## Calibration And Thresholding

Calibration is fit on validation logits only. Threshold policy is selected on validation
probabilities only. Inference may abstain with the label `indeterminate` when calibrated probability
falls inside the configured abstention interval.

## Limitations

The model is expected to overfit or underfit synthetic patterns. It does not represent scanner
diversity, contrast phases, acquisition protocols, real adrenal anatomy, pathology diversity,
radiologist labels, clinical prevalence, or external validation. Exact floating-point results may
vary across hardware and PyTorch builds.

## Safety And Ethics

Synthetic classification metrics must not be represented as clinical evidence. Future use with
public de-identified data requires provenance review, subject-level splitting, calibration review,
threshold approval, model-change control, human oversight, and clear exclusion of diagnostic use.

## Human Oversight

Human review is mandatory for all outputs. False negatives, false positives, indeterminate outputs,
miscalibration, class-imbalance effects, and failed quality gates must block downstream research use
until reviewed.

## Known Failure Modes

- Label leakage if future datasets ignore subject-level splitting.
- Class imbalance causing poor sensitivity or false reassurance.
- Miscalibrated probabilities.
- Threshold policies that create excessive false positives or false negatives.
- Abstention intervals that are too narrow or too broad.
- Checkpoint, calibration, threshold, or configuration mismatch.
- Upstream localisation or segmentation error propagation.
- Synthetic metrics misrepresented as clinical performance.
- Downstream use after failed quality gates.

## Versioning

Initial model-card version: `m9-classification-v1`.
