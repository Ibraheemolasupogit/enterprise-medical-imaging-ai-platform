# Machine learning

Implemented workflows include MONAI 3D U-Net segmentation, small CNN/Tiny ViT classification,
Faster R-CNN/Tiny DETR axial detection and CNN/ViT embeddings with exact retrieval.

[Task documentation](../docs/README.md), [model cards](model_cards/),
[synthetic dataset card](dataset_cards/synthetic_ct_dataset.md) and
[measured comparison workflow](../docs/engineering_comparison.md) describe the contracts.
Generated datasets/checkpoints remain ignored. Synthetic benchmarks establish engineering behaviour,
not clinical performance. No pretrained weights or external datasets are required by the demo.
